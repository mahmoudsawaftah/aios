---
name: item-space-acceptance
description: Use before calling a planned Item Space slice complete. Check acceptance criteria against actual implementation and evidence.
---
1. Read the approved task criteria and inspect the relevant code paths.
2. Map each criterion to implementation evidence and a meaningful test or observable check.
3. Run only project-defined checks; capture actual results.
4. Mark criteria unmet or blocked when evidence is absent. Model output alone is not acceptance.
5. Record results and gaps in `PLANS.md`; never label unrun checks as passed.
