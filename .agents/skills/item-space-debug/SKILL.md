---
name: item-space-debug
description: Use for a bug, regression, error, or failing check. Find and verify the cause before changing code.
---
1. Capture the exact symptom and expected behavior.
2. Reproduce safely with the smallest relevant test or command.
3. Trace evidence to the root cause; label hypotheses.
4. Make the smallest in-scope fix and add a regression test when useful.
5. Use `$item-space-verify` and report unverified areas.
