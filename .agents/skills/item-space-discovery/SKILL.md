---
name: item-space-discovery
description: Use before major work or when the project state, requirements, or Git root are unclear. Read and report evidence without editing files.
---
1. Confirm the selected project root and Git status; preserve all local changes.
2. Inspect the relevant source, manifests, docs, and CI. Do not recursively dump secrets or generated folders.
3. Separate observed facts, assumptions, and unanswered questions.
4. Report current behavior, gaps, and a smallest safe next step.
5. Do not edit application files during discovery.
