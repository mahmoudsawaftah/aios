---
name: item-space-plan
description: Use for multi-step work, changes spanning more than three files, or product, architecture, data, or security decisions.
---
1. Read the relevant project instructions, brief, code, and existing task plan.
2. Define goal, scope, non-goals, acceptance criteria, stages, dependencies, risks, and rollback.
3. Ground technical choices in the current repo. Flag unresolved product decisions; do not invent answers.
4. Update the active task in `PLANS.md`; avoid a second competing plan.
5. Stop for the user's decision when a material product or architecture choice is open.
