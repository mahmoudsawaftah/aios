---
name: item-space-research
description: Use when a task depends on current product, framework, security, legal, or third-party API facts.
---
1. Prefer official, current primary sources and the repository's installed versions.
2. Check publication or release dates and distinguish documented facts from inference.
3. Summarize only facts relevant to the implementation decision.
4. Cite links or file paths and explain uncertainty.
5. Do not turn research options into product decisions without user approval.
