---
name: item-space-security-review
description: Use for authentication, authorization, tenant isolation, sensitive clinic data, billing, uploads, or external integrations.
---
1. Trace the flow from untrusted input through server authorization to storage and output.
2. Check tenant scoping, role checks, validation, logging, secrets, and failure paths.
3. For migrations, assess existing data, rollback, and cross-tenant exposure.
4. Report concrete findings first with file locations, severity, and scenario.
5. Do not claim compliance with a law or security standard without verified criteria and evidence.
