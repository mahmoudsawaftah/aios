# AIOS — Item Space Edition

نسخة عمل نظيفة لتنظيم تطوير Item Space باستخدام Codex داخل Antigravity.

## ابدأ من هنا
1. افتح هذا المجلد في Antigravity.
2. افتح Codex واقرأ `AGENTS.md` و`ITEM_SPACE_BRIEF.md`.
3. تأكد من ظهور المهارات في قائمة Codex skills.
4. ابدأ بجرد قراءة فقط للمجلد `projects/Item Space/`. لا تفترض أن هناك كودًا أو مواصفات غير موجودة.
5. قبل البناء، حدّد مع المستخدم أول إصدار قابل للتجربة ومقاييس نجاحه.

## هيكل النسخة
- `AGENTS.md`: دور Codex الرئيسي، توجيه المهارات، وحدود العمل.
- `ITEM_SPACE_BRIEF.md`: آخر سياق منتج معروف مع الأسئلة غير المحسومة.
- `PLANS.md`: سجل وخطة العمل الحالية.
- `.agents/skills/`: إجراءات Codex المتخصصة للمشروع.
- `projects/Item Space/Item Space.md`: ملف فارغ كبداية.

## انتبه لجذر Git
مجلد `projects/Item Space/` placeholder داخل مستودع AIOS، وليس مستودع Git مستقلًا. إذا أردت أن يكون Item Space له مستودعه الخاص، استنسخ مستودع Item Space داخله من Antigravity أو افتح نسخة Item Space المستقلة. لا تبدأ تعديل التطبيق قبل التأكد من جذر Git الذي تريده.

## حدود الوكيل
Codex هو مهندس التنفيذ الرئيسي: يقرأ السياق، يخطط عند الحاجة، ينفذ المهمة، يفحص الناتج، ويبلغك بالأدلة. لا يعمل بالخلفية أو 24/7 من هذه الملفات وحدها، ولا يتخذ قرارات المنتج أو النشر نيابة عنك.
