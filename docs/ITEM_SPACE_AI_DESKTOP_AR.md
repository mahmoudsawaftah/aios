# item space AI — Space-themed AIOS Mission Control

الواجهة الجديدة لـ AIOS v3 تحمل اسم **item space AI**، بتصميم فضائي داكن، وتعرض الأفكار والمهام وحالتها وتقارير المراحل.

## التثبيت لأول مرة على Windows

افتح PowerShell:

```powershell
cd "C:\Users\ENG_Mahmoud\Documents\aios"
git switch feat/aios-v3-idea-console
git pull --ff-only origin feat/aios-v3-idea-console
python -m unittest discover -s tests -p "test_*.py" -v
powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\INSTALL_ITEM_SPACE_AI.ps1
```

سينشئ المثبّت أيقونة فضائية محلية في `.factory-runtime/assets/item-space-ai.ico` واختصاراً باسم **item space AI** على سطح المكتب. لا يحتاج صلاحيات مدير النظام.

## الاستخدام اليومي

- اضغط مرتين على أيقونة **item space AI** على سطح المكتب.
- ستبدأ نسخة الخادم المحلي من نفس مجلد AIOS، ثم يفتح المتصفح تلقائياً على `http://127.0.0.1:8765/`.
- نافذة التشغيل مصغرة؛ **أبقها مفتوحة** أثناء استخدام النظام.
- إذا كان الخادم قيد التشغيل بالفعل بنفس الإصدار، ستُفتح الواجهة الموجودة بدلاً من بدء نسخة ثانية.
- لا حاجة إلى كتابة `python -m factory.console` كل مرة.

**الخيار الافتراضي Safe Preview**: يتيح إضافة الأفكار وإنشاء مشاريع Git محلية، ولا يطلق Codex ولا يرفع المشاريع إلى GitHub تلقائياً. للمعالجة الآلية الاختيارية، استخدم أولاً اختبارات منفصلة ثم `python -m factory.console --auto-run` وفق سياسة الموافقات وحدود الاستخدام.

## استكشاف المشكلات

- إذا كانت الواجهة مفتوحة حالياً عبر PowerShell سابق، أوقف الخادم القديم بـ `Ctrl+C` ثم شغّل الاختصار من جديد للحصول على الشكل الجديد.
- إذا فشل فتح المتصفح: افتح `http://127.0.0.1:8765/` يدوياً. تأكد أن النافذة المصغرة ما زالت تعمل.
- إذا لم يُنشأ الاختصار: شغّل `INSTALL_ITEM_SPACE_AI.ps1` مجدداً واقرأ رسالة الخطأ.
- النظام محلي؛ لا تفتح المنفذ للعامة أو عبر Port Forwarding. لا يوجد نظام تسجيل دخول للمستخدمين عن بُعد في هذا الإصدار.
- الاختصار لا يُفعّل التشغيل مع إقلاع Windows. سيعمل **عند النقر** فقط، حسب طلبك.

التصميم الحالي لا يغيّر قاعدة البيانات أو المشاريع القديمة أو سياسات الاعتماد. جميع الملفات والبيانات تظل على القرص المحلي إلى أن يتم تشغيل العامل الآلي أو ربط خدمات خارجية بصورة مصرح بها.
