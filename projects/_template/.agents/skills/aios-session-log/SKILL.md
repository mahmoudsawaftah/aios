---
name: aios-session-log
description: Use at the end of a coding session to leave a resumable status. Update the project's existing task tracker or session note with completed work, verification, and next step. Do not create extra files when no logging convention exists.
---
1. Find the project's existing issue, task, or session-log convention and update that record.
2. Record task/branch, concise progress, changed areas, checks run and results, blockers, and the next concrete step.
3. Do not store secrets, credentials, personal data, or speculative code facts.
4. Do not commit, push, or open a PR unless the user requested it.
